Applies to: all engines; all production periods

The insufficient brake fluid level signal is sent by the special sensor to the Body Computer Node which makes it available via the B-CAN to the Instrument Panel Node. The Instrument Panel Node lights up the warning light and displays the insufficient brake fluid level message; if there is a fault the warning light displays the relevant message.

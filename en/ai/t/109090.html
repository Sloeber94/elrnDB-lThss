Applies to: all engines; all production periods

It is not possible to order key lock barrels on their own or to oder lock barrels with the spares code only. To order lock barrels, follow the special procedure described in operation 5580 - Special Accessories

Applies to: all engines; all production periods

Removing

Refitting

1. Release the retaining spring and remove it.

2. Insert the ignition key and remove the lock barrel.

Applies to: all engines; all production periods

Refitting

Removing

- Fit the retaining spring in position.

- Fit the key lock barrel in position until the click can be heard.

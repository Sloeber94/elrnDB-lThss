Applies to: all engines; all production periods

Version Without Keyless Go

The alarm system comes on automatically the moment the doors are locked using the remote control or the PASSIVE system in Belgian mode. The remote control receiver is integrated in the Body Computer Node and is fitted with an aerial for receiving the signal.

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that:the doors close mechanically using the keys which come with the vehiclethe remote controls are both working

Move on to Step

1. The doors do not lock using the key

Continue following the instructions in the table P10 CENTRAL LOCKING NOT WORKING

2. Only one remote control is working

Move on to Step

3. Both remote controls are not working

Move on to Step

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic socket and check the following at the Body Computer Node:that there are no faults;In parameters ambient:the presence of the alarm systemthe programming state of the remote controls

Move on to Step

1. The doors do not lock using the key

1. Continue following the instructions in the diagnostic table

2. Only one remote control is working

2. Check the conformity of the vehicle

3. Both remote controls are not working

3. Carry out the programming procedure for the keys and remote controls

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the Examiner diagnostic equipment to the diagnostic socket and check the following at the Body Computer Node In parameters ambient:the number of remote controls programmedthe plausibility of the remote control button parameterthe charge state of the remote control batteries

Move on to Step

1. The number of remote controls programmed is less than the number of remote controls which come with the vehicle

1. Programme the remote control, if possible, or replace the key and remote control and programme again

2. The remote control button parameter state does not change (pressed/released)

2. Replace the remote control and carry out the programming

3. The remote control batteries are run down

3. Replace the batteries

3

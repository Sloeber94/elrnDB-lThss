- Proceed with separating the fuel filler pipe from the tank, acting on the two bands.

1. Undo the ring nut (1b), using the tool (1a), then remove the fuel pump (1c), complete with level gauge.

Description

Code

Function

1a

Tool for removing fuel pump retaining ring nut

1.870.736.000

Tool for removing fuel pump retaining ring nut

The float valves and the anti-evaporation pipes connected to it cannot be replaced individually, but with the complete tank.

Applies to: engines: 2.0 TB, 2.4 20V; all production periods

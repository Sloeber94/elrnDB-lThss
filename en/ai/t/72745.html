Applies to: all engines; all production periods

When the door closing/opening is controlled using the remote control, the central locking does not work.

The Body Computer Node receives the signal from the remote control via the RF aerial. Having received the command, it sends the locking/unlocking signal to the door nodes and to the boot node which controls the locks for the rear doors and the boot lid.

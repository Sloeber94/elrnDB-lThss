Applies to: all engines; all production periods

Description

The windscreen wash/wipe system is activated by the steering column switch unit located on the right of the steering wheel, with the following functions: there are five possible positions for the lever to which the following functions correspond:

  • windscreen wiper off (stationary);
  • intermittent/automatic operation (4 positions or 4 rain sensor settings);
  • continuous slow operation (first speed);
  • continuous slow operation (first speed);
  • anti-panic temporary fast operation (unstable position).

In the intermittent/automatic operation position there are four different functions for the steering column switch unit managed by the windscreen wiper control unit.

Intermittent operation is also a function of the rain and dusk sensor (interfaced on the roof control unit) which, sends the windscreen wiper control unit a signal when the steering column switch unit is placed in the intermittent position.

The frequency of the windscreen wiper strokes is automatically adjusted depending on the amount of water on the windscreen detected by the sensor.

The Body Computer control unit acquires all the information both concerning the speed of the windscreen wiper strokes per minute and any possible failure of the rain sensor. In the latter case, or if the Body Computer does not receive information from the rain sensor via the A-BUS serial line (3 second timeout), the Body Computer sends a signal, via the CAN, to the instrument panel which displays the fault on the matrix display; as a result, the windscreen wiper control unit operates manually depending on the position of the steering column switch unit ring nut/lever. On receiving an insufficient windscreen washer fluid level signal, via the CAN, the instrument panel also displays the appropriate symbols and message on the display.

The transmission of messages between the sensor and the windscreen wiper control unit takes place via the A-BUS serial line.

The activation of the rain sensor involves a windscreen wiper arm stroke as feedback to confirm that it has been switched on.

There are 4 possible settings for the sensor which is adjusted using the ring nut on the steering column switch unit lever.

The "intelligent" windscreen washer logic is as follows:

  • on a command to wash the windscreen, the windscreen wiper control unit activates the windscreen washer pump;
  • after the pump has been activated for 0.5 seconds, the windscreen wiper is activated at the first speed;
  • the pump and the windscreen wiper remain activated for the entire period that the command to wash the windscreen exists;
  • when the control is released, the windscreen wiper control unit no longer activates the pump, whilst it still operates the windscreen wiper for a further three strokes;
  • there is an additional stroke after six seconds at the first speed (if the windscreen wiper is not already activated).

The device is temporarily excluded during starting (INT/A).

The windscreen wiper and the windscreen washer can only be activated with the ignition switched ON (INT), with the functions being disabled with the ignition switched OFF.

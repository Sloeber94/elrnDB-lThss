7025A34 bonnet lid lock (one) - r+r or repair

Applies to: all engines; all production periods

Removing

Refitting

- Disconnect the negative battery terminal.

1. Undo the nuts fixing the lock to the bracket.

2. Disconnect the flexible cable from the lock.

3. Disconnect the electrical connector (3a) and remove the lock (3b).

Description

Connector

3a

Bonnet release switch

I010

Applies to: all engines; all production periods

Refitting

Removing

- Check that the lock is not damaged.

- Connect the flexible cable to the lever located on the lock and place the lock in position.

- Check that the tailgate opening lever reaches the end of travel position correctly.

1. If this is not the case, adjust the flexible cable (1a) using the splining (1b) at the end of the actual cable.

Applies to: all engines; all production periods

1. Screw in the nuts fixing the lock to the crossmember without tightening them to torque.

- Check that the lock and the striker match correctly.

2. If this is not the case, correct the position of the lock using the openings in the actual lock.

Applies to: all engines; all production periods

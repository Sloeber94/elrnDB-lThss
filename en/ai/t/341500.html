Applies to: engines: 2.0 TB, 2.4 20V, 3.0 V6, 2.4 JTD 10V; all production periods

The Cruise Control system is not reactivated when the recall button is pressed.

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

1

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Connect the diagnostic test equipment (Examiner or other instruments) to the tester input.Check for the presence of faults in the engine management control unit

Move on to Step

1. Error detected in the control unit

1. Continue following the instructions for the diagnostic equipment

2. No communication with the control unit

2. Restore the connection between the engine management control unit and the diagnostic connector(Wiring Diagram ) E5060 CRUISE CONTROL

2

SELECTOR CONTROL CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the Cruise Control system control contacts are working properly in the recall positionContinue following the instructions in the test 5580AC Cruise Control RECALL control check

Move on to Step

No continuity

Replace the steering column switch unit lever with the Cruise Control incorporatedSee in Op. 5580A10 Cruise control LEVER ASSEMBLY - R.R.

3

SUPPLY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the ignition key in the ON position and the Cruise Control ON, check that there is a voltage signal from the Cruise Control to the engine management control unit when the recall button is pressed; (Wiring Diagram ) E5060 CRUISE CONTROL

Move on to Step

No voltage detected

Repair the connections(Wiring Diagram ) E5060 CRUISE CONTROL

4

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

Fault persists control unit defective

Replace the engine management control unitSee in Op. 1056B82 Injection/ignition system CONTROL UNIT (one) - R.R.

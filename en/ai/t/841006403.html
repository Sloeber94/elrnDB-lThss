Operational Description

The Body Computer M001 receives a supply controlled by the ignition (INT) at pin 11 of connector H interfaced with the junction unit B002: this signal is designed to wake up the network and is also used to disable several functions (rearscreen demisting, electric windows, sun roof, etc.) during starting.

The following nodes are connected to the Body Computer M001 via the C-CAN:

  • the engine management control unit M010;
  • the braking system control unit M051 (which is not connected directly, but via M010);
  • the braking system control unit M052 (which is not connected directly, but via M051 and M010);
  • the electric braking control unit M059 (which is not connected directly, but via K074 and M092);
  • the steering geometry control unit M076;
  • the adaptive cruise control system control unit M087.
  • the slewing control unit (VDC) K074 (which is not connected directly, but via M092);
  • the steering angle control unit M092.

The following nodes are connected to the Body Computer M001 via the B-CAN:

  • the roof control unit M062;
  • the luggage compartment control unit M063;
  • the passive entry control unit M064;
  • the info-telematic control unit M065.
  • the driver's door control unit M066;
  • the passenger door control unit M067;
  • the climate control system control unit M070;
  • the parking sensors control unit M084;
  • the steering lock control unit M089;
  • the steering wheel node control unit M093;
  • the instrument panel control unit E050.

The TV tuner M100 is connected to the info-telematic control unit M065 for the management of the TV function controls.

The Body Computer M001 carries out the diagnosis of the B-CAN A and B-CAN lines at pins 14 and 6 of connector I, respectively.

If there are network faults involving the control units which have an impact on several functions, the instrument panel E050 should light up the corresponding warning lights and display a CAN failure message. If there are faults involving a control unit dedicated to one single function then a specific message is displayed.

Pins 8 and 9 of connector E of the body computer are earthed.

Applies to: all engines; all production periods

Description

The exterior rear view mirrors are electrically adjusted in two directions (horizontally and vertically) using a joystick; the left or right mirror is chosen using a selector.

The driver's front door control unit acquires the adjustment commands and transmits them, via the CAN, to the passenger side.

There are three buttons on the driver's front seat controls used for the automatic recall of the positions memorized.

See E3076 ELECTRICALLY-ADJUSTABLE SEATS

See E3035 STEERING WHEEL ADJUSTMENT

See E3077 FRONT HEAD RESTRAINT ADJUSTMENT

This memory funcion is managed by the driving position control unit, which downloads seat and steering column positions directly and also door mirror positions via the CAN network. The control unit stores all the above positions when one of the three buttons is held down for at least three seconds.

A buzzer inside the instrument panel goes off when the positions have been stored.

The memory recall function is inhibited when the car is travelling faster than 10 km/h, via a signal sent via the CAN network from the Body Computer to the driving position control unit.

If command come simultaneously from the joystick and the steering control unit, the former have priority, thereby cancelling the return of the exterior rear view mirrors to the position memorized.

The rear view mirrors contain 3 motors: one for movement on the horizontal axis, one for movement on the vertical axis and one used for folding back the actual mirror. The folding function is also managed by the control unit at the driver's door which acquires the command from a button near the joystick.

The folding always applies to both mirrors, irrespective of the current position of the selector. The rear view mirror folding function is automatically deactivated by the Body Computer on the acquisition of a speedometer signal where the speed of the vehicle is above 40 Km/h.

When reverse gear is engaged (see Wiring diagram E2022 Reversing lights) thanks to the presence of a rain and dusk sensor, the electro-chromic interior rear view mirror (interfaced with the roof control unit) is immediately darkened, like the exterior rear view mirrors, allowing improved visibility.

See E2022 REVERSING LIGHTS

All the functions described are enabled in the key-on condition (INT).

Applies to: all engines; all production periods

The matrix shows a CODE fault message; the engine starts normally;

the IMMO code and IMMO code response request messages are sent normally via C.CAN line to from the Engine Control Node and the Body Computer Node. A serial line known as the W line is used if the C-CAN network fails.

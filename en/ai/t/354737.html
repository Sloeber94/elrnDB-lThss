Applies to: all engines; all production periods

One of the front door windows (driver's side or passenger side) only works manually; when the control button is pressed for longer than 300 ms and then released, the window does not open/close automatically, but stops.

The Door Node control units are programmed for both the manual and automatic movement of the windows. The specific control unit activates the manual function if the control button is pressed for beween 50 and 300 ms (briefly), whilst the automatic function is activated if the control button is pressed for longer than 300 ms (long period).

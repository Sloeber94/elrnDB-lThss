H10 STEERING HARDENING - WHEN STEERING IN BOTH DIRECTIONS

Applies to: all engines; all production periods

When the steering is operated normally there is a hardening of the steering action to both the left and the right;

No fault messages regarding the power assisted steering appear.

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECKS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the tyre inflation pressure is correctCheck that the power assisted steering fluid level is correctCheck that the power assisted steering belt tension is correct

Move on to Step

1. Tyre inflation pressure not correct

1. Restore the correct pressure

2. Power assisted steering fluid level too low

2. Restore the correct fluid level: if there are leaks, continue follow the instructions in Table X30

3. Belt tension not correct

3. Check and, if necessary, replace the belt

1

CHECK ON CONDITION OF STEERING RODS AND BOOTS

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check the condition of the steering rods and boots

Move on to Step

Rods damaged or worn

Replace the rodsSee in Op. 4110B10 Steering RODS - R.R. on vehicle - Check toe in separately

2

CHECK ON TYPE OF PROBLEM

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Conduct a test steering in various conditions checking that there are no problems.

1. Continuous and constant hardening

Move on to Step

2. Hardening only during idling

2. Check for constrictions in the (flexible and rigid) system pipes. If necessary, replace the damaged parts, replacing all the seals

3. Hardening in end of travel position

3. Restore the correct vehicle geometrySee in Op. 4450A10 FRONT WHEEL GEOMETRY - Check using optical equipment - Includes front wheel toe-in adjustment if necessary

3

STEERING COLUMN OPERATING CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the steering column rotates correctly after having disconnected it from the steering box

Move on to Step

Steering column rotation faulty

Replace the steering control shaftSee in Op. 4110A30 Support with steering control shafts - R.R.

4

STEERING BOX OPERATION CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

With the front wheels raised, make sure that the rack travels fully in both directions checking that there is no hardening or excessive clearance.

Move on to Step

Steering box operation faulty

Replace the steering boxSee in Op. 4130A10 POWER STEERING BOX - R.R.

5

CHECK ON CORRECT OPERATION

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that the fault is no longer present

Fault persists

Replace the steering boxSee in Op. 4130A10 POWER STEERING BOX - R.R.

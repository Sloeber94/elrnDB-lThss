Applies to: engines: 2.4 20V, 3.0 V6, 3.2 V6, 2.4 JTD 20V; all production periods; only with equipment: Automatic Transmission

Description

The electric handbrake system, the Parking Brake (EPB) is managed by a special electric brake controlunit which, depending on the specific command, enables the activation or the deactivation of the brake calipers on the rear wheels.

It is possible, using the controls of the info-telematic control unit, to disable the application brake calipers from one key-on state (INT) to another.

There are basically three operating modes: "STATIC", "DYNAMIC" and "Key-OFF". The operating conditions for the first mode ("STATIC") are as follows: the key-on condition and a vehicle speed of between 0 and 5 Km/h. The activation or the deactivation of the function depends on: pressing the special button located in the centre console, - for activation only - the status of the driver's front door a ( < R1 > ) end the pressure on the accelerator pedal (if the function is activated, the EPB is deactivated).

See E3040 CENTRAL LOCKING

The operating conditions for the second mode ("DYNAMIC") are: the key-on condition and the vehicle speed above 5 Km/h. The system is activated by pressing the special button and the simultaneous release of the accelerator pedal.

The only operating condition for the Key-OFF mode is the vehicle being stopped. At the key-off (OFF) the calipers are locked (EPB system activated) unless the disabling has been programmed previously using the info-telematic control unit.

Ihe instrument panel acquires via the CAN the commands for activating the "Handbrake applied" warning light (also valid for the "Insufficient brake fluid level" and "EBD braking system failure"), < R1 > ) and the failure signal for the device, directly from the electric brake control unit, through the display of a warning light, also managing the fault message on the matrix display and the signalling of the internal buzzer.

See E4010 INSTRUMENT PANEL

If one of the three systems out of the ABS, ( < R1 > ), the EBD braking system and the VDC device ( < R2 > ) is activated, then the Parking Brake function is not activated even if the user requests it using the special control.

See E7020 ABS

See E7023 ESP

If the battery is run down during the operation of the device, the electric braking control unit and the entire system will be supplied by an additional battery.

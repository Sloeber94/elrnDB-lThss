Applies to: engines: 2.4 JTD 10V; all production periods; only with equipment: Passive Entry

When approaching the vehicle and pressing the electronic button for the handle the doors do not open

The vehicle starts when the CID is placed in the garage position

STEP

OPERATIONS TO BE CARRIED OUT

TEST RESULTS

0

PRELIMINARY CHECK

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check that:the doors open using the emergency keythe doors open using the remote controlthere is no CID batteries run down message at the Instrument Panel Node.

Move on to Step

1. The doors do not open but only the mechanically controlled door opens

Move on to Step

2. The doors do not open when the remote control buttons are pressed

Move on to Step

3. Battery run down message present

3. Replace the CID batteries

1

CHECK USING ANOTHER CID

ALL OK

PROBLEMS ENCOUNTERED

ACTION

Check, using the second CID that comes with the vehicle, that the doors open both through the Passive Entry function and when using the remote control

Move on to Step

The doors do not open

Move on to Step

2

CHECK USING DIAGNOSTIC EQUIPMENT

ALL OK

PROBLEMS ENCOUNTERED

Passive Entry Node faulty

Replace the Passive Entry Node

Applies to: all engines; all production periods

The "Follow me home" function is not activated; the main beam headlamps and the dipped headlamps work normally;

The "Follow me home" function should be activated by the user within two minutes of the "key off" by operating the steering column switch unit in the headlamp flasher mode and the exterior lights control in the [PARK] or [0] positionIf the user keeps the flasher lever in the flasher position for more than two seconds the "Follow me home" function will be deactivated.the lights which come through the "Follow me home" function are the dipped headlampsthe time set by the user will be shown on the matrix that can be reconfiguredThe function should be "set" by the CONNECT.

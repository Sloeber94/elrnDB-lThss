Applies to: all engines; all production periods

Description

The headlamp washer function is only activated if the dipped or main beam headlamps are switched on.

The monostable activation command for the headlamp washer function is not a specific command, but it is the same as the one given via the steering column switch unit for the front windscreen washer function.

The Body Computer acquires both the signal to activate the function and the one to control the dipped/main beam headlamps, thereby implementing the timed operation of the headlamp washer relay. The latter activates the headlamp washer pump with successive impulses lasting about half a second.

The headlamp washer circuit is protected by a fuse located in the engine compartment junction unit.

When the instrument panel receives an insufficient windscreen washer fluid level signal via the CAN, it shows the relevant symbols and message on the display.

This function is only enabled with the ignition switched ON (INT).

Applies to: engines: 2.4 20V; all production periods; only with equipment: Automatic Transmission

Description

The car is fitted with numerous electronic control units that peform self-diagnostic functions.

It is possible to link up to each unit via a tester (Examiner or similar). This can be used to read self-diagnostic data (parameters and errors) or carry out active diagnosis.

All conections relating to the diagnostic function (on line K, and via B Can network) flow into the connector of the EOBD ( European On Board Diagnosis ), in accordance with directive 98/69/CE ( EURO3 ) - ISO standard J1962, centralised on Body Computer connector I.

Nodes connected to the network are diagnosed via the B CAN network while the dynamic car control network is diagnosed by a specific K lines.

The following are controlled via B CAN line:

  • Climate control unit;
  • the steering geometry control unit;
  • driver's door control unit;
  • passenger door control unit;
  • the roof control unit;
  • the info-telematic control unit.
  • the passive entry control unit;
  • the steering lock control unit;
  • the luggage compartment control unit;
  • the steering wheel control unit;
  • the parking sensor control unit;

The Body Computer also manages signals from control units connected to the C Can line < R1 > , in order to check that the units are working properly.

See E1050 CAN CONNECTION LINES

The following control units are connected to the body computer via the C-CAN:

  • the engine management control unit;
  • the braking system control unit;
  • the braking system check control unit;
  • the electric braking control unit;
  • the slewing control unit;
  • the steering angle control unit;
  • the steering geometry control unit;
  • the cruise control system control unit.

The following nodes are connected to the Body Computer via the B-CAN:

  • the climate control system control unit;
  • the steering wheel node control unit;
  • the driver's door control unit;
  • the passenger door control unit;
  • the roof control unit;
  • the luggage compartment control unit;
  • the passive entry control unit;
  • the parking sensors control unit;
  • the instrument panel control unit;
  • the steering lock control unit;
  • the info-telematic control unit.

the following are monitored via diagnostic line K:

  • the electric braking control unit;
  • the Servotronik control unit;
  • the headlamp alignment control unit;
  • the Air Bag control unit;
  • the adaptive cruise control control unit.
  • the braking system check control unit (brake assistance);
  • Supplementary heater control unit;
  • the engine management control unit;
  • the braking system control unit;

C37 THE VEHICLE DOES NOT START WITH THE LEVER IN POSITION P OR N

Applies to: all engines; all production periods; only with equipment: Automatic Transmission

The vehicle does not start with the lever in position P or N (the starter motor does not turn).

The starter motor relay receives a positive supply controlled by the ignition (+15) whilst the earth signal is supplied via the starting inhibitor switch for the gear lever position sensor if the lever is in position P or N

Applies to: engines: 2.4 JTD 10V; all production periods

Removing

Refitting

- Open the boot and disconnect the negative battery terminal.

See in Op. 7040D50 ENGINE COMPARTMENT UPPER SOUND INSULATION SHIELD - R.R.

See in Op. 1016A10 SOUND-PROOFING COVER - R.R.

1. Undo the nuts fixing the return manifold.

2. Disconnect the electrical wiring from the heater plugs.

3. Undo the heater plugs and remove them from the housing in the cylinder head.

The return manifold only has to be released from the housing in the intake manifold so that it is possible to dismantle the heater plug underneath; if work only has to be carried out on the other heater plugs then the return manifold is not affected.

Applies to: engines: 2.4 JTD 10V; all production periods

Refitting

Removing

- Fit the heater plugs in the special housings.

- Screw them in and then tighten them to torque.

Value - daNm

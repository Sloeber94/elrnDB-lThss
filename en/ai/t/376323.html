Applies to: all engines; all production periods

The boot lid does not open when the remote control is operated.

The boot lid opening command is received by the Body Computer Node via the internal RF receives; the Body Computer Node sends the command, via the B-Can, to the luggage compartment node which releases the lock disabling the alarm (if fitted).With the "central locking switched off", the boot lid opens activating the electric handle located on the actual boot lid.In "indepedent boot" mode, the opening of the boot lid is implemented using the remote control or by means of the mechanical key pawl.

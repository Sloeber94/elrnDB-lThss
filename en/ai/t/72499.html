Applies to: all engines; all production periods

The main beam headlamps are not working in any conditions (either in the stable lever position or flasher position);

The main beam headlamps are controlled by the Body Computer Node via a relay located in the Engine Compartment Junction Unit; the lights can be switched on/off using the following controls:The main beam headlamps are controlled by the Body Computer Node via a relay located in the Engine Compartment Junction Unit; the lights can be switched on/off using the following controls:1 Command from steering column switch unit in fixed position with go ahead via the Exterior Lights Control2 Command from the steering column switch unit in "Flasher function" unstable positionThe main beam headlamp consists of a traditional bulb (known as the "auxiliary main beam") and an electronic module connected in parallel to the bulb which supplies a coil which controls a partition which completely releases the xenon dipped headlamp.The main beam headlamp consists of a traditional bulb (known as the "auxiliary main beam") and an electronic module connected in parallel to the bulb which supplies a coil which controls a partition which completely releases the xenon dipped headlamp.
